# Architecture review — September 2026

## Scope

Review of `feature/core-traffic` before continuing with another game. The goal was to make the existing Personal Island, Parking Jam, and Junkyard Station foundation easier for agents to extend without adding a second source of truth.

## Resolved findings

1. **Incomplete ownership coverage.** Six runtime TypeScript files were outside `architecture/model.json`: both Modoki entrypoints/configs, the standalone Junkyard adapter, and shared return navigation. They now have explicit owners and dependencies.
2. **Invisible lazy dependencies.** The architecture checker only parsed static imports, so hub and game-entry `import()` edges were not validated. Dynamic imports are now resolved and checked.
3. **No cycle or source-coverage gate.** Declared dependency cycles and unowned `games/**/*.ts` files now fail the architecture check.
4. **Source-mutating delivery workflows.** One-shot workflows could unpack payloads, commit generated source, and push back into the feature branch. The workflows, scripts, corrupted archive, and marker files were removed. Architecture validation now rejects repository-content writes and staged archive payloads under `.github`.
5. **Duplicate and dead hub presentation.** An unused static HTML/JavaScript hub existed beside the actual typed runtime router; one file also contained TypeScript syntax in `.js`. The parallel launcher, unused SVG icon factory, obsolete card metadata, and card-launcher CSS were removed.
6. **Parking domain debt and hot-path allocation.** Board/path queries, semantic event creation, and passenger queue resolution were split from the command facade. One occupancy index is reused per availability query, queue processing uses an offset instead of repeated front splices, and the solver caches car/order indexes per run.
7. **Unused CI network work.** CI downloaded and uploaded island asset packs that were never consumed by the build or tests. Those steps and the duplicate fetch workflow were removed.

## Measured effect

A local diagnostic benchmark runs 12 rounds over all three levels and seeds `17`, `2026`, and `9001`. On the same Node.js 22 environment, median analysis time changed from approximately **112.7 ms** to **15.9 ms** while visiting the same 3,708 aggregate solver states. This is a local microbenchmark rather than a release SLA; correctness remains enforced by deterministic domain tests.

## Deferred debt

- Parking presentation controller, scene, model factory, and CSS remain above the default size limits and retain explicit ceilings in `quality/debt.json`.
- Billiards remains a design contract only. It must not appear in the hub registry, Pages routes, or PR acceptance claims until real source, tests, build output, and browser evidence exist.
- No visual redesign or new gameplay was included in this review.
