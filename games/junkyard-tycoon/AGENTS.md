# Junkyard Station agent rules

- The domain owns resources, objectives, unlocks, and rewards.
- The presentation reads domain state and events; it never awards cash, scrap, construction, or completion.
- Character movement and interaction progress must reuse `games/shared/proximity-world/domain`.
- New workstations define semantic interaction IDs and focused models; do not fork the controller.
- Keep the weak-device profile playable before adding decorative density.
- Do not copy third-party code, names, level layouts, assets, branding, or exact visual compositions.
