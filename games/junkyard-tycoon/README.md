# Junkyard Station

An original vertical slice for the reusable Slop tycoon-world base.

Starter loop:

1. move near the mechanic or one of three junk piles;
2. remain nearby while the action icon fills;
3. earn scrap and cash from junk;
4. build the first fuel pump;
5. refuel a customer;
6. collect the payment at the register.

The domain composes `games/shared/proximity-world/domain`. Presentation owns the low-poly scene, keyboard/touch input, floating action icon, character animation, and adaptive renderer quality.
